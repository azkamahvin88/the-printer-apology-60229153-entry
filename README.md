A deterministic Python program that writes one one-line apology note from an office printer to the people who keep jamming it — "I am sorry I jammed. You fed me paper, staples and a paperclip, and called it a balanced diet" — to `/output/entry.txt` for make.fun's "The Printer Apology" bounty.

## Run it

```sh
python3 main.py
```

## How it works

`main.py` (Python standard library only, no network, no randomness) holds one fixed joke string and writes it to `/output/entry.txt`. Two runs produce byte-identical output. See [STUDY.md](STUDY.md) for how the joke was chosen from 22 candidates scored against the judge's brief.
